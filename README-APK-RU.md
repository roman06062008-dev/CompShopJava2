# Как получить APK CompShop без Android Studio

В этом архиве находится исходный проект Android на Java и GitHub Actions workflow, который собирает APK в облаке. Сам APK в архив пока не включён: его нужно собрать один раз в облаке.

## Что понадобится
- аккаунт GitHub;
- браузер на телефоне или компьютере;
- интернет.

## Шаги
1. Распакуйте архив `CompShopJava.zip`.
2. Создайте на GitHub новый **публичный** репозиторий с именем `CompShopJava` (можно выбрать Private, если понимаете, как загружать туда файлы). Не добавляйте README или другие стартовые файлы.
3. Загрузите в репозиторий **содержимое** папки `CompShopJava`, включая скрытую папку `.github/workflows`. В репозитории в корне должны быть `settings.gradle`, `build.gradle`, папка `app` и папка `.github`.
4. Откройте вкладку **Actions**. Если GitHub попросит, разрешите запуск workflows.
5. В списке слева выберите **Build CompShop APK**, затем нажмите **Run workflow** → **Run workflow**.
6. Дождитесь зелёной отметки успешной сборки. Откройте завершённый запуск и внизу раздел **Artifacts**.
7. Скачайте `CompShop-debug-apk` и распакуйте ZIP. Внутри будет `app-debug.apk`.
8. Откройте APK на Android-телефоне и подтвердите установку. Если телефон попросит разрешение, разрешите установку приложений из этого источника только для используемого приложения (например, браузера или файлового менеджера).

## Если вкладка Actions не появилась
Проверьте, что файл `.github/workflows/build-apk.yml` находится именно по этому пути в корне репозитория, а не внутри ещё одной вложенной папки.

## Важно
- Это отладочный APK для установки и демонстрации, он не подписан для публикации в Google Play.
- Для установки Android может потребоваться разрешить установку неизвестных приложений для браузера/файлового менеджера.
- Приложение — демонстрационный прототип: заявки не отправляются на реальный сервер.
